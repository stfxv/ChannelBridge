# ChannelBridge

RME などの多チャンネル入力から必要なチャンネルを選び、他のアプリに2チャンネルの **ChannelBridge Mic** として渡す macOS ミニアプリ。

Rustによるアプリ・仮想ドライバの全面再実装を進めています。[実装計画](RUST_REWRITE_PLAN.md)と[進捗・検証範囲](RUST_PROGRESS.md)を参照してください。`crates/` は開発中で、現在のインストーラや通常版をまだ置き換えません。Rustの基礎検証は `bash scripts/test-rust.sh` で実行します。

## 使い方

1. `dist/ChannelBridge.app` を Applications フォルダに置いて起動します。
2. 初回のみ「仮想マイクをセットアップ」で同梱インストーラを実行し、Macを再起動します。管理者認証はmacOS Installerが扱います。
3. 入力デバイス、入力チャンネル、モードを選び、マイク使用を許可します。開始前から入力レベルを確認できます。「開始」で仮想マイクへの送出を始めます。
4. 通話・文字起こし・録音アプリ側で **ChannelBridge Mic** を入力に指定します。
5. ウィンドウを閉じても送出は続きます。メニューバーのマイクアイコンから開く・停止・終了ができます。輪郭のマイクは送出停止中、塗りつぶしは送出中、斜線付きは送出ミュート中です。

BlackHole や LadioCast の別途インストール・起動は不要です。既存の BlackHole とは別のUIDで共存します。システムの既定入力・出力は変更しません。初回ドライバ導入には再起動が必要ですが、通常のサンプルレート変更ではアプリの再起動を不要にする設計です。

## サンプルレート変更への対応

- 入力の現在のレートを読み、同梱仮想ドライバのレートを合わせます。RMEの設定自体は変更しません。
- レート・チャンネル数・切断・音声コールバックの停止を監視します。
- 変更を検知したら内部の private aggregate を停止・破棄し、入力が1秒安定したら自動で再構築します。失敗時は最大8秒間隔で再試行します。
- 入力デバイスは一時的な数値IDでなくUIDで保存します。再接続時も同じ入力に復帰します。
- 単一の2ch仮想デバイスを送出・受信に共用し、別デバイス間でレート変更が伝わらない問題を避けます。HALのドリフト補正を有効にして、物理入力と仮想デバイスのクロック差を吸収します。
- 「停止」は送出とその自動再開を解除します。マイク使用が許可されていれば、保存した入力のレベル確認は起動時から動きます。音声の保存・外部送信はしません。アプリ終了時に入力の読み取りも止まります。
- レート変更中には短い無音区間が生じます。無停止・無音声欠落の切替を保証するものではありません。
- 仮想デバイスのレート変更に対応しない受け取り側アプリでは、入力デバイスの再選択が必要な場合があります。RME実機と利用アプリの組み合わせで受け入れテストが必要です。

## モード

- モノラル: 選んだ1chを左右両方へコピー。
- ステレオ: 選んだ2chを左右へ。
- ミックス: 選んだ2chを平均して左右へ。合算で6 dB大きくなることを避けます。
- 送出ミュートは音声経路を再接続せず切り替えます。アプリ内の音量調整はなく、入力をそのまま送出します。以前の設定に `gain_db` が残っていても無視します。過大な出力は±1に制限します（音質を保つリミッターではありません）。

## 入力レベルとフォーマット

- 選択した入力チャンネル番号とピーク値を **dBFS** で表示します。無音は `−∞ dBFS`、入力が未接続・マイク未許可などで読み取れない場合は `—` です。
- 「開始」前・送出停止中も入力だけを読み、選択したチャンネルのレベルを表示します。仮想マイクのインストール前でも利用でき、物理・仮想デバイスのサンプルレートは変更しません。
- 開始すると入力確認用の経路を送出用の経路に切り替え、停止すると入力確認へ戻ります。確認中も切断・サンプルレート変更から自動復帰します。
- 各チャンネルのミックス・送出ミュート・出力クリップ前の入力を測定するため、ミュート中も入力の有無を確認できます。モノラルでは選んだ1入力のみ、ステレオ／ミックスでは2入力を別々に表示します。
- 250 msごとの更新までのピークを保持します。最大値はさらに3秒残し、0 dBFS以上を赤で表示します。入力メーターの目盛りは−60〜0 dBFS、数値はより小さい信号も表示します。
- 入力デバイスのサンプルレート（kHz）と、選択チャンネルのドライバ報告形式（bit／整数・float）を表示します。取得できないbit数は推測せず「bit 取得不可」と表示します。
- ここでいうbit数はCore Audioの入力ストリーム形式です。AD変換器の分解能とは異なる場合があります。アプリ内の処理・仮想マイクは別表示の **32 bit float** です。
- 「全入力のレベル」で選択デバイスの各入力を一覧表示できます（最大512ch）。一覧内のチャンネルをクリックすると左 / モノ入力に選択します。一覧を閉じると全入力の追加計測を止めます。
- チャンネル数が減った場合、選択は「現在使用不可」として残ります。ミュートやモード変更でCh1へ勝手に置き換えません。
- デバイス情報は変更通知で更新し、通知が届かない場合にも5秒ごとに読み直します。開始・再接続は画面とは独立した処理で行い、メニュー操作中も復旧監視を続けます。
- 設定保存に失敗した場合は元の設定と接続を維持します。未対応形式は繰り返し再接続せず、入力形式が変わるか「更新」「開始」で再試行するまで待ちます。

## ビルドと構成

macOS 13以上、Go 1.24以上、Xcode Command Line Tools。外部Goモジュール、Electron、ブラウザサーバーは不要です。

```sh
./scripts/test.sh
./scripts/build.sh
```

アプリはビルドしたMacのCPU向け、ドライバはApple Silicon/Intel両対応です。ローカル用のad-hoc署名で、Developer ID署名・公証は未実施です。他のMacへの一般配布には署名・公証を追加してください。

- `cmd/channelbridge`: Goの設定・状態管理・復旧監視と、画面から独立した制御ワーカー。
- `internal/settings`: Goの検証と設定保存。
- `internal/native`: AppKit画面、Core Audio接続、Cの音声ミキサー。
- `vendor/blackhole`: 固定バージョンの上流HALドライバ。
- `driver`: 別名化と互換性パッチ。
- `scripts`, `packaging`: ソース同梱・ビルド・初回セットアップ。

アイコンは明るいグレーの土台に黒いマイクを置いたモノトーンの図案です。内蔵画像生成ツールで作成した透過PNGを `packaging/assets/AppIcon.png` に保存し、生成プロンプトも同じフォルダに同梱しています。ビルド時にmacOS用の全サイズを作り、ICNSとしてアプリへ組み込みます。
起動時に同梱画像をDockへ明示設定します。メニューバーでは背景色に追従するmacOS標準のマイク記号を使い、明暗どちらでも視認性を保ちます。

音声コールバックからGoを呼びません。リアルタイム処理はメモリ確保・ログ・ロックのないC層に閉じ、GoのGCによる音切れを避けています。ネイティブ層はHALが提供するnative-endian float32 PCMのみ対応し、未対応形式は開始前に拒否します。

GitHub ActionsでもGoの最低対応版と安定版でテスト・アプリビルドを実行します。スレッドの責務やAIによる変更時の確認事項は [ARCHITECTURE.md](ARCHITECTURE.md) にまとめています。

## 確認が必要な実機テスト

1. RMEの任意の上位チャンネル（例: Ch 9）を選んで、受け取り側で左右に同じ音が届くこと。
2. 送出中・受け取り側使用中に 44.1 → 48 → 96 → 44.1 kHz を切り替え、再起動せず復帰すること。
3. ADATのSMUX切替などでチャンネル数が変わる際、不正なチャンネルへ勝手に切り替わらないこと。
4. USB切断・再接続、スリープ復帰後に選択が保たれて復帰すること。
5. 停止中のレート変更・再接続では入力メーターだけが復帰し、送出は自動再開しないこと。
6. 開始前からCh 9などの入力メーターが動き、選択変更とミュートに追従すること。終了すると入力の読み取りが止まること。
7. ミュート・解除で再接続が発生せず、入力メーターは動き続けること。全入力の一覧から音が出ているチャンネルを選択できること。
8. レート変更中にメニューを開いたままでも画面が応答し、復旧すること。
9. 通話アプリと録音アプリを開いたまま、30分以上音切れ・ずれがないこと。

## 削除

アプリを終了して削除します。仮想マイクも削除する場合は Finder の「移動 → フォルダへ移動」で `/Library/Audio/Plug-Ins/HAL` を開き、**ChannelBridge.driver のみ**を削除してMacを再起動します。設定は `~/Library/Application Support/ChannelBridge/settings.json` に保存されます。
